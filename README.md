Desarrollado y respaldado por **Nevora Software**.

## Identidad del Producto
- **Nombre comercial:** VELTOR
- **Empresa desarrolladora:** Nevora Software
- **Frase de marca:** Financiamiento inteligente. Movilidad a tu alcance.
- **Mercado inicial:** El Salvador (USD, America/El_Salvador)
- **Pie de página oficial:** "VELTOR — Una solución tecnológica de Nevora Software"

- **Sitio público:** VELTOR
- **Catálogo:** Vehículos disponibles
- **Simulador:** Simulador de financiamiento VELTOR
- **Panel administrativo:** VELTOR Administración
- **Portal privado:** Mi VELTOR

- **Módulo de cobros:** Pagos y cobranza
- **Reportes:** Informes financieros

## Tecnologías
- React 19 + TypeScript + Vite
- Tailwind CSS
- React Router DOM
- TanStack Query (React Query)
- React Hook Form + Zod
- Lucide React
- Chart.js / Recharts
